**Known limits after this wave:** the local parser is a bounded rule set. Each adversarial review round found new phrasing classes that produced a wrong agreement; all found so far are fixed, and unrecognised wording now falls to uncertainty, but the grammar is not closed. About half of correct held-out read-backs are still flagged (false alarms), which is the cost of that caution. Devanagari "रवि" does not match a Latin-script owner "Ravi".
